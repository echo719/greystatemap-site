Boreas Isle

The single map revealed so far. No playable build exists yet, so there are no verified coordinates — this page holds what is confirmed and the map shell that gets populated on day one of the playtest.

Interactive map — not yet populated

Extraction points, loot spawns, monster locations and Vertex spawns will be plotted here once a playtest build is available. We will not publish guessed coordinates.

What is confirmed about Boreas Isle

  • A remote, rugged island setting in Northern Europe.
  • Distinct zone types shown in the PvE gameplay trailer: industrial complexes, hilly open terrain, an abandoned village, and an urban area.
  • It is the primary location for the co-op PvE mode.
  • Extraction is two-tier: a safe, low-value extraction, or a single helicopter at a contested final exfil point for the main objective.

What is not known

  • Map dimensions and whether it is one contiguous area or split into sectors.
  • Number and location of extraction points.
  • Loot tiers and spawn tables.
  • Where The Vertex spawns, and whether the spawn is fixed or randomised.
  • Whether PvP and PvE use the same version of the island.
  • Whether more maps exist. Only Boreas Isle has been shown.

Why this page is empty on purpose

Extraction-shooter map sites live or die on accuracy — a wrong extract marker gets somebody killed and loses the site its readers. Boreas Isle has appeared only in trailer footage, which is edited and cannot be triangulated into reliable coordinates. So the shell ships now, the data ships when it can be verified in a build.
