About this site

GreyStateMap is an independent fan project. It is not affiliated with, endorsed by, or connected to Grey State Studio or Tencent.

What we do

We track Rules of Engagement: The Grey State and publish an interactive map, class references and a status board. The game is not out yet, so most of this site is currently a fact log rather than a database — that is deliberate.

Three rules we hold to

  1. Every claim is dated and sourced. If we cannot point at a primary source, it does not go on the page.
  2. We do not invent data. No guessed map coordinates, no fabricated talent nodes, no “best build” for a game nobody has played. Empty is better than wrong.
  3. We correct in public. When we get something wrong we change the page and note it, rather than quietly editing.
