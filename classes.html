The three revealed Strider classes

Grey State Studio has shown three classes so far. Talent trees exist but their contents have not been published, so we describe roles only — no invented numbers.

No stats yet. The game has a talent tree per class, but no node list, cost or percentage has been published. Any site showing you a “best build” today made it up. Ours goes live when a playtest build does.

Sledge

Role: frontline. Sledge is the shield-carrying class — the one that walks into a monster horde first and holds a corridor while the squad works.

Confirmed: shield-wielding, described as the durable frontline pick.
Unknown: shield health, whether the shield is deployable or carried, movement penalty, talent tree contents.

Pyro

Role: area control. Pyro uses gas and fire — the tools you bring when the threat is a crowd rather than a single target, which matches the game's monster-horde PvE mode.

Confirmed: gas and incendiary weapons and abilities.
Unknown: damage-over-time behaviour, friendly-fire rules, resource costs, talent tree contents.

Phantom

Role: stealth. Phantom is built to move unseen — the class most obviously aimed at the PvP half of the game, where reaching the exfil before a rival squad notices you matters more than winning the fight.

Confirmed: stealth-oriented kit.
Unknown: whether stealth is true invisibility or detection reduction, duration, counterplay, talent tree contents.

How many classes will there be?

Three have been shown. The studio has described “multiple player classes” and post-launch seasonal content, which implies more later, but no fourth class has been named. We are not going to list rumoured ones.

Squads are 3 players, so class combinations matter — but until abilities have real numbers attached, any synergy advice would be fiction.
